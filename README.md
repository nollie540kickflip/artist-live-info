# お気に入りアーティスト ライブ情報

お気に入りアーティストのライブ情報をリスト表示する Web アプリ。Muse 内アプリとして作成したもののソースコードをエクスポートしたリポジトリ。

## 機能

- アーティストは利用者自身が登録／編集／削除（名前が必須、公式サイトURL・検索用キーワード・メモは任意）
- 登録したアーティストのライブ情報は、公開情報から自動取得
  - 登録時に初回取得、「今すぐ更新」ボタン（全体／アーティスト別）で再取得、毎日 06:00（JST）の定期取得
  - 新規公演は追加し、日程・会場・発売日時などの変更は反映するが、付けたステータスとメモは自動更新で上書きしない
  - 同一公演の重複（手動登録分と自動取得分など）は1件に統合する
- ライブ一覧：アーティスト絞り込み（横スクロール1行）、ステータス絞り込み（プルダウンで複数選択：取得済み／気になる／チケット発売待ち／見送り）、日付順ソート
- 終了を過ぎた公演は一覧・件数に表示しない
- 先頭に「次のライブ」までの日数と、まもなく発売開始の公演をコンパクトに表示

## 構成

- `client/` — React クライアント
- `server/src/actions.ts` — サーバーアクション（アーティスト管理・自動取得・重複統合ロジック）
- `server/src/schema.ts` — DB スキーマ
- `drizzle/` — マイグレーション SQL

## 注意

- Muse のランタイム（`@hatch/space-sdk` はローカルファイル依存）前提のコードのため、そのままでは Muse 外での単体起動は想定していない。コードの保管・参照用。
- 登録データ（`app.db`）や監査用スクリーンショットは含めていない。
